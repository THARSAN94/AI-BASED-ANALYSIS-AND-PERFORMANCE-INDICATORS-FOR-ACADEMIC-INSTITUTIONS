# AI-Based Analysis and Performance Indicators for Academic Institutions

An AI-based Academic Performance and Approval Eligibility Analysis System for Indian higher-education institutions. It pre-evaluates college readiness for **AICTE** (Approval Process Handbook) and **UGC** (Section 2(f) / 12(B)) approvals, identifies compliance gaps, and generates AI-powered recommendations using the Gemini API.

## Features

- **AICTE & UGC compliance assessment** — criterion-by-criterion evaluation against statutory benchmarks (land, faculty, FSR, labs, library, corpus fund, safety NOC, committees, etc.)
- **Database-driven criteria** — benchmark thresholds are editable at runtime (not hardcoded) with reset-to-defaults support
- **Gap analysis & recommendations** — automatic identification of unsatisfied criteria with prioritized action items
- **AI executive summary** — Gemini-generated consultant-style summary of each assessment
- **Authentication & dashboards** — JWT-based login/registration, assessment history, and stats
- **Responsive UI** — React 19 + Tailwind CSS 4 with multiple themes

## Tech Stack

| Layer     | Technology                                        |
| --------- | ------------------------------------------------- |
| Frontend  | React 19, Vite 8, Tailwind CSS 4, TypeScript      |
| Backend   | Express (Node.js), run via `tsx`                  |
| Database  | JSON file store (`data/database.json`, auto-seeded on startup) |
| AI        | Google Gemini via `@google/genai`                 |
| Auth      | JWT (`jsonwebtoken`) + `bcryptjs`                 |

## Getting Started (Local Development)

**Prerequisites:** Node.js 20+

```bash
npm install
```

1. Copy `.env.example` to `.env` and set `GEMINI_API_KEY` (see [API Key](#api-key)).
2. Run the dev server:

```bash
npm run dev
```

Open http://localhost:3000.

> **Demo login:** `admin@institution.edu.in` / `password123`

## API Key

The app needs a **Gemini API key** for the AI executive summary feature (the rest of the app works without it):

1. Go to [Google AI Studio](https://aistudio.google.com/apikey) and create a free API key.
2. Locally: put it in `.env` as `GEMINI_API_KEY=...`
3. On Render: add it as an environment variable (see below).

## Deployment on Render

A `render.yaml` blueprint is included, so Render will auto-detect the service configuration.

1. Push this repository and create a **New Web Service** on [Render](https://render.com/) from it (or use the Blueprint option pointing at `render.yaml`).
2. Settings (already filled in by `render.yaml`):
   - **Runtime:** Node
   - **Build command:** `npm install && npm run build`
   - **Start command:** `npm start` (serves the Vite production build via Express)
   - **Health check path:** `/api/health`
3. Add these environment variables in the Render dashboard:
   | Key | Value |
   | --- | ----- |
   | `GEMINI_API_KEY` | Your Gemini API key *(Secret)* |
   | `JWT_SECRET` | A long random string (auto-generated by the blueprint) |
   | `NODE_ENV` | `production` |
4. Deploy — Render provides the URL (e.g. `https://<service>.onrender.com`).

### Notes

- **Ephemeral storage:** the JSON database is written inside the container, so user registrations/assessments reset on redeploys or free-tier sleep. For persistent data, attach a **Render Disk** and point the app at it (or migrate `server/db/store.ts` to a hosted database like Render's PostgreSQL).
- `PORT` is injected automatically by Render; the server honors it.
